# AI Usage Declaration

This project was built with AI assistance (Claude by Anthropic) in a pair-programming style.

## What AI helped with

- Angular syntax and patterns (first Angular project; prior experience in React/Next.js)
- Debugging TypeScript and compiler errors
- Identifying public GBFS feed URLs for multiple cities and operators
- Suggesting code structure for services, signals, and RxJS patterns

## What the developer drove

- All architectural decisions: feature-sliced folder structure, adapter pattern, signal-based store
- The multi-feed city selector concept and UX design
- Choosing HTML Markers over GeoJSON layers (based on understanding the worker limitation)
- Reviewing, understanding, and validating every line of code before integrating it
- Debugging map rendering issues (tile provider, worker setup, marker lifecycle)
- All Git history, commit structure, and project milestones

## How AI was used

Conversational pair-programming — the developer asked questions, proposed ideas, and made
final decisions. AI did not autonomously generate or commit code without review.
